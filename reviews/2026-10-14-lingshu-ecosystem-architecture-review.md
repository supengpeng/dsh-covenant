## 一、逐条对照与判定

### ✅ ACCEPT（结构同构，可直接采信）

**F1 · 五层执行 × 三档隔离 × 三层报告 = A10 分层原则的同构实现**
`architecture.md:95-101`（五层执行）＋ `:81-89`（三档隔离）＋ `:182-190`（三层报告）与 A10 的七处分层同属一个模式。**判定 ACCEPT。**

**F2 · 「最小信任」= A5 否决式融合的同向实现**
`:55`「不信任插件自述与宿主行为，只信外部可观察证据（能力要实测，不轻信声明）」；`:145-147` 三探头信任分级（宿主/环境＝客观事实，插件自述＝声明须实测）。
这与 A5 的 **证据 ≻ 概率** 同向：声明是概率（可能是什么），实测是证据（物理上发生了什么）。**判定 ACCEPT。**
> **建议补强**：A5 还要求「每维设硬下限，任何一维低于阈值直接否决」。covenant 的能力矩阵有四态但**没有硬下限否决**——建议加：任一必需能力维为「已探测不存在」⇒ 直接 REJECT，不进入加权。

**F3 · 「判定精确 · 无隐式通过」= A9 四态判定的工程化**
`:46`「显式 `verdict` 枚举（pass/fail/skip/error/inconclusive），**无隐式「通过」**」；`:151`「能力缺失/未验证时打 skip 或 inconclusive 并附证据，**绝不产生假 pass/fail**」。**判定 ACCEPT。**
> **【复核收窄】** 原稿称「covenant 把 DEFER 与 BLINDSPOT 合并为 inconclusive」——不准。`:146` 的第四态「不可探测（分得清支持 / 不支持 / 没证据 / 只是嘴上说）」已含 BLINDSPOT 的近似语义；`inconclusive`（判定层）与「不可探测」（能力层）不是同一个合并动作。**准确表述：两层各缺一半**——能力层缺 DEFER 的「继续递归找区分条件」，判定层缺 BLINDSPOT 的「停止猜测」显式化。拆分建议仍成立。

**F4 · 「完整性可验证」= A8 完全确认「无内部矛盾」**
`:53`「报告带『应跑清单 / 已跑清单 / 覆盖缺口』，**证明无静默跳过**」。这正是 A8「跨时间稳定 ∧ 无内部矛盾」在报告面的落地。**判定 ACCEPT。**
> **【复核撤销】** 原稿另称「也直接对上 B3（能红）」——**归属过宽，撤销**。B3 原义是「完成判据必须**能红**（可构造一个必失败的检验）」；`:53` 只提供「未跑可见」，不构成必失败检验。B3 在 covenant 全文**无对应**（见 §三 G6）。

**F5 · 「权威内核 = 签名 JSON 证据链」= A4 结构锚定记录**
`:186`「带签名的 JSON 证据链：**append-only、内容寻址**、绑环境快照 + 工具/模型版本 + 种子；机器可读、**可重放验证**」。**判定 ACCEPT（一项强、一项部分）。**
> **【复核弱化】** 原稿称两项都「对上」——第二项偏弱。A4 的「可独立校验」是**离线副本一致性校验**（只需副本 + 状态摘要）；covenant 的「可重放验证」是**运行复现**（需环境快照 + 工具/模型版本 + 种子）。二者不等价。准确表述：**不可篡改 = 对上；可独立校验 = 仅部分对应**。

**F6 · 「本地面孔／对外面孔」= B2 的「只做镜像」结构**
`:182-190`：权威内核（签名 JSON）→ 本地面孔（HTML）→ 对外面孔（JUnit/TAP 适配器）。权威面唯一、面孔派生，与 B2 的 (a)(b) 同构。**判定 ACCEPT（结构）。**

**F7 · §14 风险 #2 的自我声明是诚实的，且已兑现**
`:256`「现成 `cordis-host-runner` 源码细节待核实……**当前设计层仅作参照，未逐行核实**」。作者主动标注未核实面，符合 B4「未取证不进设计」的口径。**判定 ACCEPT（诚实性加分）。**

### ❌ REJECT（结构性缺口，建议补）

**F8 · 缺「验证单元的独立复核位」与「终裁位」——单点风险**
A3 要求：验证单元的计算**必须接受反思单元的独立复核**；不一致时由维生系统裁决。
covenant 的 9 模块（`:114-124`）中，**断言 SPI（模块 3）是「判」的产生位置**（`:118`），模块 1 只是「收集判定」（`:116`）；全文检索「复核」＝ **0 命中**（复核独立实测确认）。
**判定 REJECT。**
> **【复核修正论证】** 原稿称「**谁判定断言 SPI 判得对？没有位置**」——**过强**。`:141`「做与判分离：组合图里能分清『观测节点』与『判定节点』，断言可独立插拔」已提供**多判定者并列的容器**；`:158` 的「人工确认」也是对**建议**的复核位。
> **准确表述**：位置容器存在，缺的是——① **「判定须经独立复核」的义务**（无任何条款要求断言 verdict 被独立复核）；② **终裁位**（A3 的维生系统对应物，不一致时由谁裁决）。
> **建议补法**：按 A3 补两个位置——(1) 断言结果须经独立复核（可由另一断言实现或元断言做）；(2) 不一致由第三位终裁并留痕。

**F9 · 缺「裁决的监督」与「申诉面」——平台自身行使准入权却无人监督**
A13：裁决理由可被审查／**成员可申请复核**／委员会执行复核／年度全面审查；外部校准的独立性。
covenant 的定位是**市场准入门禁**（`:124`「对外双入口：本地自检 / 市场门禁」）——这是一个**行使裁决权的系统**。但全文检索（验证单元独立复核确认）：「申诉」＝ **0**，「复核」＝ **0**，「校准」＝ **0**。
即：插件作者被判 fail 之后，**无申诉通路**；平台的判定规则**无外部校准**。**判定 REJECT（本评审最重的一条）。**
> **【复核边界】** A13 监督的对象是**维生系统的终裁权**；covenant 的 `fail` 是**质量判定**，外部后果是影响插件上市。映射成立（同属行使裁决），但**不是同一权力**——此边界须写明。
> **建议补法**：按 A13 补三件——(1) 判定理由可审查（证据链已具备，缺「可被异议」的口子）；(2) 插件作者可申请复核（对应协作架构 §3.4 的「退回返工」，且**不扣分**）；(3) 判定规则的**外部校准者**与独立性声明。

**F10 · 缺「跳闸留痕」——静默删闸的入口**
B1 明确：**砍闸 ≠ 自动通过，免闸必须显式留痕**（谁判的免闸、命中哪几条判据），「否则等于把闸静默删除」。
covenant 的「运行清单 = 矩阵（插件×版本×环境×宿主适配器）+ 场景选择」（`:281`）允许**选择场景**，但没有规定「某层不跑」时须留痕。全文检索「砍」＝ **0 命中**。**判定 REJECT。**
> **【复核补正证据】** 原稿只引 `:281`；**更直接的原文在 `:175-176`**：「技术门禁（契约校验 + 首跑探测）**恒在**，过了即自动可用；人工门禁只在『离开本地、对外发布』时触发」——这才是「免闸」的实际形态（本地路径**默认免人审闸**）。`:53` 的「覆盖缺口」已给「未跑可见」半边；B1 要的是「**免跑的授权留痕**（谁判的、命中哪几条判据）」，确无。
> **建议补法**：运行清单须配一条「未跑层/未跑场景」的显式记录字段，并说明免跑依据；与 B1 的五条判据同口径。

**F13 · 缺「多节点冗余」——证据链的单点**
A4 的结构锚定记录三要求：不可篡改／可独立校验／**多节点冗余**（「记录应在多个独立节点上存有副本，防止单点丢失」）。
`:186` 满足前两项，全文检索「冗余」＝ **0 命中**。**判定 REJECT（设计期可接受，实施前须定）。**
> **建议补法**：声明证据链的副本策略（哪怕只是「本地 + 一份只读归档」），并写明单点丢失时的重建路径。

### ⏳ DEFER（条件未定，须继续找区分条件）

**F11 · 缺「镜像不得反写权威面」的显式化** —— **【复核改判：REJECT → DEFER】**
B2 的 (a) 是硬判据：「**禁止双写真相**」。covenant 把 HTML 与 JUnit/TAP 定义为「面孔」（派生），**结构上对**。
> **【复核推翻原事实前提】** 原稿称 covenant「**没有写出这条禁令**」——**不实**。`:48`「规格先行 | 契约与场景先建模成可执行规格，断言与报告由规格生成，**不从结果反推**」＋ `:157`「…是『什么才叫合法组合』和『到底执行了什么』的**唯一真相源**」——评审担心的路径（从 HTML 报告反推/回填证据链）已被 `:48` **明文挡住**。
> **真缺口**只是 B2 的 (c)(d) 未显式化：「**判定只读权威面**」「**冲突以权威面为准**」。属显式化补充，不是须阻断的结构缺口。
> **建议补法**：在 §11 加两句 (c)(d)，并把 `:48`「不从结果反推」提升为面孔层的显式禁令。

**F12 · Fiber 状态机缺「DISPOSED 不可重启」硬契约** —— **【复核改判：REJECT → DEFER，撤销两处不成立的断言】**
covenant `:231-236` 画：

```
PENDING → LOADING → ACTIVE → UNLOADING → DISPOSED
                     ↘ FAILED
```

真源 `@deepseek-ai/cordis` 的 `lib/types/fiber.d.ts:67-74`：

```ts
export declare const enum FiberState {
    PENDING = 0, LOADING = 1, ACTIVE = 2,
    FAILED = 3, DISPOSED = 4, UNLOADING = 5
}
```

同文件 `:62-65` 注释：「`DISPOSED` — the fiber **was removed and cannot restart**」。
**判定 DEFER。**
> **【复核撤销①】** 原稿称「该枚举是六个并列值，不是一条带分支的线性链」——**层次混淆，不成立**。`:67-74` 是 TS `const enum` 的**常量定义**（编译器产物），语义顺序在 `:62-65` 注释里，且注释顺序即 `PENDING→LOADING→ACTIVE→FAILED→UNLOADING→DISPOSED`；covenant 画的是**状态机语义图**，与真源注释不矛盾。
> **【复核撤销②】** 原稿称「漏了 PENDING 也可直接 FAILED」——**无出处**。真源摘录只写「`PENDING` — waiting for required services；`FAILED` — the callback or its config threw」，**PENDING→FAILED 的转移在真源摘录中不存在**，属超出真源的推论。
> **成立的部分**：缺「**DISPOSED 不可重启**」这条硬契约（真源明载）——而 covenant `:8-14` 的多插件冲突检测会反复装载/卸载，`:89` 又自认 `node:vm` 不是安全边界。
> **建议补法**：把「DISPOSED 不可重启」写成冲突检测场景的一条前置约束，并直接引用真源枚举。

**F14 · 缺 A6「通道可信度」——只有静态证据分级，没有动态通道命中率**
`:47`「可信度显式：每个判定绑定**证据来源 + 可信级**（静态源码 / mock 契约 / 真实宿主 / 重放快照）」。
这对应的是 A7 **锚定分级**（证据来源越接近物理基底，Gain 越大）。但 A6 是**另一个维度**：「**置信度 ≠ 可信度**；可信度＝**通道历史验证命中率**」。covenant 缺这一维——即「同一个断言实现，历史上判对过多少次」。
**判定 DEFER**：这不是错误，是**尚未到需要它的阶段**。平台若长期运行、断言 SPI 可插拔，则该维必然需要。**建议在实施期补，不阻塞设计定稿。**
> **【复核收窄】** 原稿称该分级「方向**正确**」——须收窄。按 A7，**强验证 = 行动/世界裁决**；而 covenant 把「**重放快照**」列在最高档——重放是**历史录制回放**，不是当次行动裁决，且比「真实宿主」更依赖录制时的条件。**准确表述：前三档（静态源码 < mock 契约 < 真实宿主）方向正确，第四档（重放快照 > 真实宿主）存疑。**

**F15 · 原判「缺 A12 稳定性条件」** —— **【复核改判：DEFER → 撤销（判据映射失真）】**
A12 原文（`:2224-2230`）是**分布式协议副本**的复用判据：「协议副本覆盖率 ≥50%／信息交换密度／动态重组触发」——多节点语境。covenant 是**单机元插件**架构，全文无「多节点」「副本覆盖率」概念。
> **【复核推翻】** 原稿把它读成「断言 SPI 至少要覆盖多少类判定、宿主适配器至少几档才算覆盖充分」——**这是原稿自创的映射，不是 A12 原义**。**本条撤销**；「组合充分性下限」可作为**独立建议**保留，但不挂在 A12 名下。

**F16 · 未锁真源版本**
covenant 用 `Cordis Fiber / Service / Schema` 等术语，方向对，但**未声明所依据的 DSH 版本**（`:228-241`）。文档未锁版本 ⇒ 未来漂移不可判。
**判定 DEFER**：建议在 §13 补「真源版本 = DSH x.y.z / cordis a.b.c」，使契约可复核。

### 🕳 BLINDSPOT（无法建立判断路径，停止猜测）

《灵枢协作架构_设计 v0.1》§8.3 自述：「本稿**没有做对抗性验证**——未构造『故意破坏』实验证明这些闸在真实攻击下有效」；《智能论 v3.4》给出负路由对抗数据（28% → 88% → 91%，并强调「全新机制的新对抗集（防打补丁）」）。
